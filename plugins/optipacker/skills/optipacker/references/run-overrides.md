# Explicit run inputs

Read the live `prepare_proposal` input schema and the prepared `reviewBrief`. The schema defines supported keys; the brief states the effective values.

- `overrides.settings`: the complete canonical settings object. It includes `gapConfiguration` in mm, `initialOrientation` as quarter turns 0–3, `rotationConstraints`, `useCustomGaps` and `layerDistributionMode`. Preserve the member's intended independent axis permissions. A setting that permits rotation does not prove that every possible orientation was evaluated.
- `overrides.cycleDays`: named loop stages in days. It is a partial patch of the fresh default stages. The server recomputes the total. To request a total such as 21 days, agree the stage breakdown with the member and send all stages that need replacing; changing one stage to 21 would add the other default stages.
- `overrides.costOptions`: canonical cost options, including coverage and optional `additionalCosts`. Each additional item has `category` (`handling`, `switching` or `residual`), calendar `year`, USD `amount` (`{value, unit: "usd"}`) and `evidence`. The currency enum is lowercase in tool inputs. Supply each programme year to which an annual cost applies. Confirm whether a cost is shared or alternative-specific before entry. For an amount in the named organization currency, divide by the prepared rate (organization-currency units per USD), re-prepare with explicit USD values and show the rate. If the amount uses a different currency, obtain a matching authoritative rate, ask for its USD equivalent or complete entry on the website. Never label an amount USD while leaving its EUR value unchanged.
- `overrides.materialAssumptions`: explicit recorded operating inputs or supported library bands for containers, inserts or pallets. Preserve evidence and estimate status. Read the current benchmark version from the returned `reviewBrief.materialAssumptions[].library.version` before supplying a library basis.

`costScope` marks categories not applicable with the member's reason. It takes no amounts. Costs with no known value or justified exclusion stay unknown. A website draft is local form state; a later MCP preparation does not import that state. For an unsupported input finish the custom comparison on the website.
